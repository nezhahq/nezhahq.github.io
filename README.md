# Nezha Monitoring V2 Documentation

Official Chinese and English documentation for [Nezha Monitoring V2](https://nezha.wiki/), an open-source, self-hosted server monitoring and operations platform.

The documentation covers:

- Dashboard and Agent installation
- Multi-server metrics and availability
- HTTP, Ping, TCP, and TLS certificate checks
- Alerts and notification providers
- Terminal, files, tasks, DDNS, NAT, REST API, and MCP
- Architecture, security, version compatibility, and troubleshooting

## Official projects

- [Nezha Dashboard](https://github.com/nezhahq/nezha)
- [Nezha Agent](https://github.com/nezhahq/agent)
- [Chinese documentation](https://nezha.wiki/)
- [English documentation](https://nezha.wiki/en_US/)
