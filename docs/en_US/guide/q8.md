# Using Cloudflare Access as an OAuth2 Provider

::: warning
The original content of this page applied to the V0 OAuth2 configuration format and does not apply to current V2 releases. This page is kept only to preserve old links; do not use the old format for a new Cloudflare Access login setup.
:::

Cloudflare Access uses the current OAuth2 configuration structure, as described below.

Refer directly to [Setting Up OAuth 2.0 Binding](/en_US/guide/q14.html#cloudflare-access). That document includes the Callback URL, configuration fields, and Cloudflare Access example available in the current version.
