## 让监控数据变成下一步行动

**哪吒 MCP 让 AI 助手连接你已接入哪吒的服务器：查状态、读日志、执行命令、管理文件，并检查操作结果。** 你用自然语言提出目标，AI 组织步骤，哪吒提供实际操作服务器的工具。

MCP（Model Context Protocol）是一种让 AI 使用外部工具的标准协议。已有哪吒的用户可以复用现有连接，无需在每台服务器上安装大模型；模型与对话由你选择的 AI 客户端提供。

### 日常运维，少一些来回切换

- **多台服务器，一起检查。** 汇总各台机器的状态和问题，减少逐台登录、复制命令和整理结果的重复工作。
- **从发现问题，到处理问题。** 不只解释监控指标，还能读取相关日志、运行诊断，并执行你授权的操作。
- **操作之后，再检查一次。** 对比变更前后的配置和服务状态，让“命令执行成功”有实际检查结果支撑。
- **用你熟悉的 AI 工具。** 把服务器管理接入 Codex、OpenClaw 或 Claude Code，访问哪些机器、允许哪些操作由你控制。

## 四个可以开始使用的场景 {#scenarios}

前两个场景提炼自实际多机巡检和内存告警处理经验；后两个展示可搭建的工作流。

### 1. 多机巡检：先找出需要关注的服务器

> “检查所有授权服务器的磁盘空间和软件运行环境，列出需要处理的问题。无法连接的机器单独列出，先不做修改。”

AI 获取服务器清单、检查状态并执行检查命令，整理成逐台报告。遇到安全更新，还可以区分宿主机与容器内的软件，帮助确定检查和更新范围。

**你得到：** 哪些机器需要处理、依据是什么、哪些还没查清。离线或未查到的项目不会被混同为正常。

### 2. 告警排障：从“内存满了”找到下一步

> “这台机器为什么频繁出现内存告警？查进程和相关日志，给出处置建议，先不要停止服务。”

AI 结合当前状态、进程和系统日志分析原因，提出针对性方案。内存占用最高的进程不一定是被系统终止的进程；对照日志，可以避免只凭一个指标作判断。

**你得到：** 可能的原因、检查依据和可审阅的处置方案。需要持续处置时，可把审阅后的脚本交给哪吒告警触发任务；告警和任务在后台或通过 REST API 配置。

### 3. 配置变更：改完之后，确认服务真的可用

> “检查这份配置修改。先保留原文件和差异，按批准方案修改，再检查语法和服务是否正常。”

AI 读取配置、准备差异，通过文件工具检查写入冲突，再执行适合该服务的检查与重载命令。备份、批准和恢复步骤需要在工作流中安排。

**你得到：** 修改了什么、检查是否通过、服务是否恢复的记录，而不只是一句“已执行”。

### 4. 日常自动化：在聊天里收到巡检结果

> “每天汇总服务器状态；收到告警后先排查，只在预先批准的范围内处理，再告诉我结果。”

将哪吒 MCP 接到已配置的助手定时任务或告警通知流程，AI 就能在需要时收集现状、分析问题并交付摘要。定时运行、接收告警和发送消息由助手或外部工作流提供。

**你得到：** 日常巡检摘要，以及结合现场情况的告警响应。自动处置范围由你预先确定，不是启用 MCP 就默认全自动接管。

## 选择你熟悉的 AI 工具

- **Codex：** 在修改代码、配置或排查部署问题时，直接检查服务器环境并验证修改效果。
- **Claude Code：** 在对话中串联日志检查、诊断命令与文件修改，逐步完成排障。
- **OpenClaw：** 从聊天入口发起巡检，再结合已配置的定时任务和消息渠道组织日常运维。

使用支持 HTTP MCP 和 Bearer Token 的客户端接入。OpenClaw 需配置当前运行时可用的 MCP 客户端或 mcporter；具体设置见[连接 AI 客户端](/guide/mcp.html#connect-clients)。

## 开始使用：先完成一次状态检查

**还没安装哪吒？** 先[安装 Dashboard](/guide/dashboard.html) 和 [Agent](/guide/agent.html)，让服务器上线。已经接入的用户可以直接开始：

1. **开启连接：** 在哪吒后台启用 MCP，创建专用访问令牌（PAT），限定可访问的服务器和工具。
2. **接入助手：** 按[接入指南](/guide/mcp.html#connect-clients)配置客户端，确认能读到授权服务器清单。
3. **试一次只读查询：** 发送下面的请求，核对返回的机器和状态；之后再按需开放命令执行与文件写入。

> “列出我有权限查看的服务器，汇总在线状态和磁盘使用情况。不要执行命令或修改文件，把无法确认的状态单独列出。”

::: tip 从查询开始，逐步增加自动化
MCP 默认关闭。命令执行使用服务器上哪吒 Agent 的运行权限；启用执行权限不等于只读权限。涉及停服、删除或配置变更时，在 AI 客户端中安排确认步骤。详细说明见[权限与安全](/guide/mcp.html)和[数据隐私](/guide/security.html)。
:::

## 常见问题 {#faq}

### 哪吒 MCP 是什么？

哪吒 MCP 是连接 AI 助手与服务器的标准工具接口，提供服务器清单、当前状态、远程命令和文件操作。AI 负责理解需求，哪吒负责提供实际操作工具。

### 可以与 Codex、OpenClaw、Claude Code 一起使用吗？

可以使用支持 HTTP MCP 和 Bearer Token 的客户端接入。Codex 和 Claude Code 支持远程 MCP；OpenClaw 需配置当前运行时可用的 MCP 客户端或 mcporter。

### 哪吒内置大模型或聊天机器人吗？

不内置大模型。哪吒提供监控与运维工具，模型、对话、规划和工作流编排由你选择的 AI 客户端负责。

### MCP 能直接配置告警、查询历史指标或管理所有面板设置吗？

MCP 提供服务器状态、命令和文件工具。告警与任务配置、历史指标和其他面板设置，需要使用哪吒后台或 REST API。

### 能实现自动化故障处置吗？

可以搭建诊断、授权处置和复核流程。定时运行、接收告警和操作确认由客户端或外部工作流提供；哪吒触发任务可以执行审阅后的脚本。

### 自托管后，数据还会发送给 AI 服务商吗？

Dashboard 与服务器 Agent 可以自托管。使用外部模型时，客户端可能将提示词、工具结果及读取到的日志或文件发送给模型服务商；具体取决于模型部署方式和客户端的数据策略。
